___
{: .note-title }
> This project is still being worked on

### About
I wanted to make a cool website using php, so I started working on it and then found out about [neocities](https://neocities.org) and wanted to be as creative as some of the people that I saw. But as of now its bland, as I'm going to try and add content first and then style it later.

It was mainly the first couple steps that I took into web-dev, since it was really easy to set up in localhost and then portforward to my server, but I realize that if I want to keep improving it that I should try learning frameworks like React so that I can both make webpages that look nice and not bore myself to death rewritint the same html blocks over and over again.

### Plans
- Finish adding basic content that is shown in the navbar
- Theme the website while still having a low [carbon footprint](https://www.websitecarbon.com)
- Get the website to 100% on [internet.nl](https://internet.nl/site/happylizard.me/4241113/#) (Currently 82%)
